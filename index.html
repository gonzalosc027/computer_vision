El origen: demasiado ambicioso, y el punto de partida de todo

El proyecto original era un analizador de campos de golf con imágenes de satélite: detección automática de hierba sana, zonas estresadas, bunkers y árboles. Era técnicamente muy ambicioso — etiquetado automático por color HSV, corrección adaptativa de iluminación, refinamiento geométrico de contornos — y a pesar de todo el esfuerzo invertido, no llegó a quedar completamente pulido. Eso abrió la puerta a dos proyectos adicionales más acotados y mejor terminados: un analizador de tráfico en tiempo real con YOLOv8 y OCR, y un sistema completo de segmentación semántica con SegFormer sobre ADE20K (150 clases). Tres pipelines end-to-end, tres aplicaciones web funcionales.

Proyecto 01
Golf Course Analyzer
Análisis automático de salud de campos de golf mediante visión aérea e IA
EfficientNet-B0 Transfer Learning OpenCV Streamlit Weak Supervision PyTorch

📋 Descripción

Sistema de visión por computador que analiza ortofotografías aéreas de campos de golf (imágenes de dron o satélite) y detecta automáticamente el estado del terreno: zonas de hierba sana, hierba estresada, bunkers y árboles. El resultado es un diagnóstico visual completo con métricas de salud, mapas de color y recomendaciones automáticas de actuación para el greenkeeper.

⚙️ Pipeline de 5 etapas

1. Organización → 2. Preprocesado HSV → 3. Entrenamiento CNN → 4. Inferencia + Post-proc. → 5. App Streamlit

🗄️ Dataset

  • 3.370 ortofotografías de campos de golf daneses
  • Etiquetado automático por color HSV (weak supervision)
  • Eliminación de duplicados con perceptual hash
  • División 70% train / 15% val / 15% test
  • Augmentación: flip, rotación, brillo, ruido gaussiano

🧠 Modelo

  • EfficientNet-B0 con transfer learning desde ImageNet
  • Clasificación de patches de 64×64 px con solapamiento 32px
  • 25 épocas, early stopping tras 6 sin mejora
  • Checkpoint guardado: models/best_model.pth
  • CrossEntropyLoss con class weights ponderados

✨ Técnicas avanzadas

  • CLAHE: normalización adaptativa de iluminación (sol/sombra)
  • Refinamiento por forma: contornos con ≥6 vértices = bunker real
  • Corrección de franjas: detecta y reclasifica zonas de corte alterno
  • Detección adaptativa de árboles: aprende el color por imagen
  • Mapa de confianza por píxel (probabilidad máxima del modelo)

🌐 Aplicación web

  • Análisis individual: métricas, mapa de segmentación, overlay
  • Comparación temporal de dos fechas (mapa de cambios)
  • Health Score (0–100) + Nivel de estrés automático
  • Medición de áreas reales en m² y hectáreas
  • Exportación de informe PDF completo
Cómo ejecutarlo: instala dependencias con pip install -r requirements.txt, luego python3 run_pipeline.py 5 y abre localhost:8501. Sube cualquier ortofoto para ver el análisis.

Proyecto 02
Smart Traffic Analyzer
Detección de vehículos, estimación de velocidad y lectura de señales en tiempo real
YOLOv8n ByteTrack EasyOCR Fine-tuning Streamlit Apple MPS

📋 Descripción

Aplicación web de análisis de tráfico que procesa imágenes, vídeo grabado o cámara en directo. Detecta y clasifica seis tipos de vehículos con tracking individual (ByteTrack), estima la velocidad de cada uno con corrección de perspectiva, detecta señales de límite de velocidad mediante HSV + OCR y genera informes PDF y CSV descargables. Incluye un modelo propio fine-tuned sobre COCO.

⚙️ Pipeline de 5 etapas

1. Descarga COCO → 2. Preprocesado + Aug. → 3. Fine-tuning YOLOv8 → 4. Inferencia + mAP → 5. App Streamlit

🗄️ Dataset

  • 2.000 imágenes del COCO 2017 val set
  • Filtrado: solo imágenes con vehículos de 6 clases
  • Conversión COCO JSON → formato YOLO txt
  • Split: 80% train (~1.600) / 20% val (400 + 5 background)
  • Aumentación: mosaic, HSV jitter, flip, scale, erasing

🧠 Modelo

  • YOLOv8n fine-tuned propio: models/best.pt
  • 30 épocas, batch 8, imagen 640×640 px, AdamW
  • Mejor época 28: mAP50 = 0.4808
  • Bus: AP50 0.06 → 0.51 (+753% con fine-tuning)
Bug crítico corregido: el mapeo erróneo de IDs COCO hacía que los camiones nunca se detectasen (IndexError silencioso). Solución: diccionario explícito COCO_TO_NAME.

✨ Funcionalidades destacadas

  • Velocidad con perspectiva: escala dinámica por tamaño de bbox
  • Heatmap acumulativo de concentración de vehículos
  • Línea de conteo virtual con dirección arriba/abajo
  • Señales de velocidad: HSV + Hough + morfología + OCR
  • Carteles de dirección: azul/verde con validación por texto
  • Densidad de tráfico: Fluido / Moderado / Denso / Colapso

▶️ Cómo ejecutarlo

  • pip install -r requirements.txt
  • Entrenar (opcional): python3 train.py — genera models/best.pt
  • Lanzar app: streamlit run app.py → localhost:8501
  • Sube una imagen, vídeo o conecta una cámara IP/USB
  • Si no hay modelo propio, usa YOLOv8n genérico automáticamente

Proyecto 03
Segmentación Semántica · ADE20K
Sistema completo de segmentación de escenas con 150 clases sobre el dataset ADE20K
SegFormer-B0 HuggingFace PyTorch Gradio albumentations pytest

📋 Descripción

Dado cualquier fotograma, el sistema produce un mapa denso de etiquetas semánticas que asigna una clase a cada píxel: cielo, coches, personas, edificios, vegetación, etc. — 150 categorías en total. El pipeline cubre desde la descarga automática del dataset ADE20K hasta la aplicación web interactiva con interfaz Gradio, slider de opacidad y leyenda dinámica de clases detectadas.

⚙️ Pipeline de 5 etapas

1. Adquisición ADE20K → 2. Preprocesado + Aug. → 3. Fine-tuning SegFormer → 4. Inferencia + mIoU → 5. App Gradio

🗄️ Dataset

  • ADE20K scene_parse_150 (MIT CSAIL)
  • 3.000 train + 500 val + 200 test (desde HuggingFace Hub)
  • 150 clases semánticas, anotación píxel a píxel
  • Desbalance compensado con CrossEntropyLoss ponderada
  • Aumentación: flip, brillo/contraste, rotación 90°, blur

🧠 Arquitectura: SegFormer-B0

  • Encoder Mix Transformer (MiT-B0): 3.7M parámetros
  • Decoder All-MLP: minimalista, ~0.4M parámetros
  • Base: nvidia/segformer-b0-finetuned-ade-512-512
  • Fine-tuning: 10 épocas, AdamW lr=6e-5, CosineAnnealingLR
  • mIoU de referencia (sin fine-tuning propio): ~37%
¿Por qué SegFormer-B0? Balance ideal: suficientemente preciso en ADE20K y ligero para correr en CPU / Apple Silicon sin GPU NVIDIA.

✨ Aplicación Gradio

  • Subida de imagen por drag & drop, click o portapapeles
  • Pestaña Segmentación: máscara coloreada pura (150 colores)
  • Pestaña Overlay: blend ajustable con slider de opacidad
  • Leyenda dinámica: solo clases presentes, ordenadas por área
  • Tiempo de inferencia + dispositivo mostrados en pantalla
  • Galería de ejemplos precargados para demo rápida
Cómo ejecutarlo: pip install -r requirements.txt → python3 src/etapa5_app.py. El modelo se descarga automáticamente desde HuggingFace (~90 MB) y la app abre en localhost:7860.

🧪 Suite de tests automáticos

  • Tests con pytest, organizados por etapa (4 ficheros)
  • Validación de shapes de batch (8, 3, 512, 512)
  • Verificación de rango de máscaras [0, 149]
  • Forward pass sin NaN + mIoU final > mIoU inicial
  • Inferencia sobre 3 imágenes de internet + cobertura 100% píxeles
  • Detección de clase 'sky' en imágenes de paisaje

Reflexión y herramientas

Estos tres proyectos me han servido para aprender cosas que no había tocado antes: YOLO para detección de objetos, tracking con ByteTrack, lectura de texto en imágenes con OCR, filtros HSV para segmentar por color, o arquitecturas como SegFormer para segmentación semántica. También he montado interfaces web con Streamlit y Gradio para que los modelos sean utilizables. No todo ha salido perfecto y hay partes que se podrían mejorar.

Para el desarrollo he usado varias herramientas de IA: Copilot para ir corrigiendo errores sobre la marcha, Claude para ayudarme con partes del código, y ChatGPT para pulir el texto de la memoria.
